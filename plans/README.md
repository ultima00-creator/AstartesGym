# Planos Astartes:Opengym

## Angus Whitby · SBD 5 semanas

- `whitby-sbd-5w.opengym.json` — plano importável no openGym (5 rotinas da semana 1 + 30 exercícios customizados).
- `whitby-sbd-5w.xlsx` — periodização completa das 5 semanas (225 lifts) para o leitor.

### Como importar o JSON

No app: Plan → Share → Import plan file → escolha o `.opengym.json`.

As rotinas são adicionadas (merge). O schedule da semana substitui o atual se você marcar a opção.

### Tema mármore

`frontend/src/marble.css` — ative com `data-theme="marble"` no `<html>` ou importe no `main.jsx`.

As cargas do Training antigo (`sbd-whitby-v1`) não se mexem. Este é o plano estrutural.
